# Unix Shell Emulator — Этап 1

## Запуск

Из корневой директории проекта выполните:

```bash
chmod +x run.sh
./run.sh
```

Для завершения работы эмулятора введите `exit`.

## Запуск тестов

Сделайте скрипты тестирования исполняемыми и запустите общий набор тестов:

```bash
chmod +x tests/run_tests.sh tests/test_commands.sh tests/test_errors.sh
./tests/run_tests.sh
```

Для запуска тестов Go выполните:

```bash
cd src
go test
```

## Описание функций

### `main.go`

- **`main()`** — запускает программу и вызывает интерактивный режим.
- **`runInteractive()`** — организует цикл ввода команд, выводит приглашение, передаёт команды на выполнение и завершает цикл при вводе `exit`.

### `executor.go`

- **`execute(command string) int`** — подставляет переменные окружения, разбирает команду и аргументы, обрабатывает `ls`, `cd`, `exit` и неизвестные команды, возвращает код результата.
- **`ok`, `commandError`, `exit`** — константы для успешного выполнения, ошибки и завершения программы.

### `promt.go`

- **`makePrompt() string`** — формирует приглашение командной строки на основе имени пользователя, имени компьютера и текущей директории.

После запуска появится приглашение командной строки. Для завершения работы введите:

## Тестирование

Запустите эмулятор командой `./run.sh` и проверьте следующие команды.

**1. Команда `ls` без аргументов**

```text
ls
```

Ожидаемый результат: вывод имени команды и пустого списка аргументов.

**2. Команда `ls` с аргументами**

```text
ls -a /tmp
```

Ожидаемый результат: вывод имени команды и переданных аргументов.

**3. Подстановка переменной окружения**

```text
ls $HOME
```

Ожидаемый результат: вместо `$HOME` выводится значение переменной окружения `HOME`.

**4. Команда `cd`**

```text
cd /tmp
```

Ожидаемый результат: вывод имени команды и переданных аргументов. На первом этапе команда не изменяет текущую директорию.

**5. Обработка неправильных аргументов**

```text
cd /tmp /home
```

Ожидаемый результат: сообщение об ошибке `cd: too many arguments`.

**6. Обработка неизвестной команды**

```text
unknown
```

Ожидаемый результат: сообщение `unknown: command not found`.

**7. Завершение работы**

```text
exit
```

Ожидаемый результат: эмулятор завершает работу.

## Описание функций

### `main.go`

**`main()`**

Основная функция программы. Создаёт приглашение командной строки, запускает цикл чтения пользовательского ввода, передаёт введённые команды на выполнение и завершает работу при получении команды `exit`.

**`runInteractive()`**

Запускает интерактивный режим эмулятора. В цикле выводит приглашение командной строки, считывает введённую пользователем команду и передаёт её функции `execute()` для обработки. Цикл продолжается, пока пользователь не введёт `exit` или не произойдёт ошибка чтения ввода.

### `executor.go`

**`execute(command string) int`**

Обрабатывает и выполняет введённую команду:

- Подставляет значения переменных окружения с помощью `os.ExpandEnv`.
- Разбирает строку на команду и аргументы с помощью `strings.Fields`.
- Игнорирует пустой ввод.
- Обрабатывает команды `ls`, `cd` и `exit`.
- Выводит сообщение об ошибке, если команда неизвестна или переданы недопустимые аргументы.
- Возвращает код результата выполнения команды.

**`ok`, `commandError`, `exit`**

Константы, обозначающие успешное выполнение команды, ошибку выполнения и необходимость завершить эмулятор соответственно.

### `promt.go`

**`makePrompt() string`**

Формирует приглашение командной строки на основе данных операционной системы: имени пользователя, имени компьютера и текущей рабочей директории.
